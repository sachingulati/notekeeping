## Question
What was made during this work that is worth keeping, but is not a note?

## Admission
Files the work produced and a later reader may want: pages - a decision page, a summary page -
screenshots, and output files.

## Exclusion
Knowledge -> the item's notes or the registers; a page only shows what they hold, and anything
decided on one is written back to them. A throwaway file - a scratch script, a log read once - is not
kept.

## Entry format
**A folder of files, named in kebab-case**, at `work/<bucket>/<id>/artifacts/`. **`summary.html` is
reserved for `/nk:summary`**, which writes that file and no other here.

**Nothing is required to be in it, and no skill depends on what is.** A file arrives because someone
chose to keep it; the folder is not filled by any command.
